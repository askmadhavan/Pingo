## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/askmadhavan/Pingo/security/advisories/new).

Include the affected version, your OS, reproduction steps and the impact. You
can expect an acknowledgement within 3 working days and a status update within 10. Once a fix is released, we will credit you in the advisory unless you prefer
to stay anonymous.

## Scope

In scope: the desktop app (`src/`), the release pipeline, and the website.
Out of scope: issues that require an already-compromised machine, and
unsigned-binary warnings from SmartScreen or Gatekeeper (a known limitation).
